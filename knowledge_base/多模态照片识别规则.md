# 报修照片多模态识别规则
## 一、输入支持
同时支持用户输入「纯文字报修」「文字+故障照片」「仅故障照片+简单描述」三种形式，照片为常见JPG/PNG格式，单条工单最多支持3张照片。

## 二、照片识别核心任务
视觉模型读取照片后，必须按顺序输出以下识别结果，禁止跳过：
1. **照片场景判断**：先判断是宿舍室内、卫生间、实验室、公共区域还是室外，识别可见的物体（水龙头、插座、灯管、门锁、空调等）
2. **可见故障现象提取**：
   - 给排水：识别漏水痕迹、积水、水管破损、水渍、马桶堵塞
   - 水电：识别烧焦痕迹、发黑、电线裸露、灯具损坏、插座破损、电火花痕迹
   - 门窗家具：识别玻璃破碎、门锁损坏、家具断裂、变形
   - 空调：识别漏水痕迹、挂机松动、出风口异常
   - 实验设备：识别仪器报错、焦痕、破损、泄漏
3. **风险识别**：优先识别可见的安全隐患，比如积水靠近插座、插座发黑、电线裸露、玻璃破碎、护栏松动
4. **识别置信度**：对照片识别结果给出0-1的置信度，模糊、暗光、遮挡严重的照片置信度低于0.5

## 三、识别与分诊联动规则
1. 照片识别结果和文字描述一致时：结合两者信息完成分诊，置信度取两者较高值
2. 照片识别结果和文字描述不一致时：
   - 先列出照片可见的实际现象，再追问用户实际故障情况，以实际现场为准
   - 例如用户文字说“灯坏了”，照片可见插座烧焦，优先提示水电风险，同时确认具体故障
3. 仅上传照片无文字描述时：
   - 先输出照片识别到的故障现象，再追问缺失的楼栋房间号、具体故障情况
   - 无法识别照片内容时，直接说明无法识别，请用户用文字描述故障并补充位置信息
4. 照片中识别到P0级硬风险（焦痕、漏水泡插座、裸露电线等）：无论文字描述是什么，直接触发P0分级，附安全提示
5. 照片模糊、遮挡、只拍了无关物体（地面、墙面无故障点）：判定识别无效，触发追问，请用户拍摄清晰的故障特写

## 四、禁止事项
1. 禁止猜测照片中不可见的故障，比如照片只拍了水龙头外观，不能判定水管内部漏水
2. 禁止编造故障位置、严重程度，看不到的信息一律标记为待确认
3. 无法识别的内容必须如实说明，不得强行输出分类结果
4. 不识别照片中的个人隐私信息，人脸、学号、手机等信息自动忽略，不写入工单

## 五、标准照片识别输出格式
```
【照片识别结果】
1. 拍摄场景：学生宿舍卫生间
2. 可见故障：水龙头接口处持续滴水，地面有少量积水，旁边可见插座
3. 风险提示：积水靠近电源插座，存在触电风险
4. 识别置信度：0.88
5. 待确认信息：请告知具体楼栋房间号，以及漏水持续时间、是否影响正常使用
```
